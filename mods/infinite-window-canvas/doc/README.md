# Infinite Window Canvas

Infinite Window Canvas is a Windhawk tool mod that treats ordinary windows on
the monitor under the pointer as a virtual canvas. When the pointer dwells near
a monitor edge, the windows on that monitor move together, revealing their
layout beyond the physical screen edge without an Alt+Tab switch.

The mod runs in a dedicated windhawk.exe tool-mod process and moves windows
with normal Win32 window positioning. It does not capture or mirror window
content. The pointer stays inside the physical desktop while the canvas moves.

## Layout

- src/metadata.h contains the Windhawk metadata, English and Chinese readme,
  and settings.
- src/context.h owns the thread, layout, and setting state.
- src/windows.h filters and tracks windows on the active monitor.
- src/canvas.h applies virtual offsets and edge-dwell panning.
- src/picker.h draws the native quick jump picker.
- src/control.h owns the message-only host window, frame timer, and reset
  and quick jump hotkeys.

The release artifact is generated by python tools/bundle.py; never edit the
generated .wh.cpp file by hand.

## Usage

Move the pointer near a monitor edge and hold it there. After the configured
dwell time, ordinary windows on that monitor pan in the pointer direction.
Leave the edge to stop. Speed rises as the pointer approaches the screen edge,
and the edge easing value decides how gentle the start of the ramp is.

Press Ctrl+Alt+Win+Q to open the quick jump picker. It lists every managed
window on the active monitor. Double-click or press Enter to center the
highlighted row, press 1 to 9 to pick a row directly, and press Esc to cancel.
The chosen window is centered and brought to the foreground. Press
Ctrl+Alt+Win+R to restore the layout captured when the mod started (or the
active monitor layout, if the pointer moved to a different monitor).

Both hotkeys are configurable in the Windhawk settings. The quick jump hotkey
takes a full combination such as Ctrl+Alt+Win+Q or Ctrl+Shift+F9; an empty value
disables the picker, and an unparsable value is logged and ignored.

The edge trigger distance default is 48 pixels, the dwell time is 250 ms, the
maximum pan speed is 1800 pixels per second, and the easing is 20.

Panning is limited to outer edges, the sides of a monitor that face empty
desktop space. Edges shared with another monitor keep their normal behavior so
the pointer can still cross between displays. Any mouse button pauses panning,
and moving the pointer to another monitor returns the previous monitor layout
to its origins before a new layout is captured.

The process blacklist accepts executable names such as notepad.exe, one entry
per row.

## 中文说明

无限窗口画布会把鼠标所在显示器上的普通窗口视为一块可平移的虚拟画布。
鼠标在屏幕边缘停留超过设定时间后，窗口会一起平移，从而看到物理屏幕边界之外的
窗口布局，无需频繁使用 Alt+Tab。

该 mod 使用标准 Win32 窗口定位来移动窗口，不复制或镜像窗口内容。鼠标本身仍然
停留在物理桌面内，移动的是窗口画布。默认按 Ctrl+Alt+Win+R 可以恢复起始布局。

默认按 Ctrl+Alt+Win+Q 打开快速跳转选择器：列表中列出当前显示器上的所有受管窗口，
双击或按 Enter 让选中的窗口居中，按 1 到 9 直接选择，按 Esc 取消。两个热键都可以
在 Windhawk 设置里修改，快速跳转热键需要填写完整组合（如 Ctrl+Shift+F9），
留空则关闭该功能。

默认边缘触发距离为 48 像素，停留时间为 250 毫秒，最大平移速度为每秒 1800 像素，
缓动强度为 20。鼠标越靠近屏幕外侧，平移越快。

平移只在外侧边缘触发：与另一台显示器相邻的边缘仍保留切换显示器的行为。按住任意
鼠标键会暂停平移；鼠标移到另一台显示器时，原显示器上的窗口会先回到起始位置。
