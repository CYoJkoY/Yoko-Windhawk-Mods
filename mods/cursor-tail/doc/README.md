# Cursor Tail

Adds a speed-sensitive cursor trail with optional click, wheel, and motion
feedback plus pendant ornaments. The mod runs as a Windhawk tool mod inside its
own `windhawk.exe` process and draws into a layered overlay window.

## Layout

- `src/metadata.h` holds the Windhawk metadata, readme, and settings blocks.
- `src/context.h` owns all mutable state in a single `ModContext` instance.
- `src/hooks/` holds the overlay window procedure; the remaining headers cover
  settings, sampling, rendering, and ornaments.
- `dist/cursor-tail.wh.cpp` is generated by `python tools/bundle.py` and is the
  only file that should be submitted to the Windhawk mods repository.

Do not edit the generated bundle by hand. Change the modular sources and rerun
the bundler.
